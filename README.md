Gentlii Skills

Gentlii Skills is a local-first, AI-powered toolkit for making  product management easier. It helps product teams define their products, validate feature ideas, and make informed decisions based on strategy, user needs, and available evidence.

Gentlii Skills consists of two core capabilities:

1. Product Definition

Product Definition helps create and maintain a clear Product Vision based on existing information, user needs, and feedback.

It supports:

- Analyzing available product information.
- Identifying missing information and assumptions.
- Asking targeted questions to clarify product direction.
- Defining target groups, needs, features, business goals, and differentiators.
- Generating and maintaining a structured Product Vision.

2. Feature Validation

Feature Validation helps evaluate proposed features against the Product Definition.

It supports:

- Assessing alignment with the Product Vision.
- Identifying the user problem a feature aims to solve.
- Evaluating expected user and business value.
- Identifying assumptions, risks, and trade-offs.
- Providing actionable recommendations: Proceed, Refine, Validate First, or Reject.

## Core Principles

- Local-first: Product information is stored and managed locally.
- Lightweight: Minimal setup.
- Evidence-based: Distinguish facts from assumptions.
- Product-aligned: Validate features against the Product Definition.
- Outcome-oriented: Focus on user and business value.
- Human-controlled: AI supports decisions but does not make them.

## How It Works

Gentlii Skills uses a minimal set of Markdown-based product information.
Product Definition establishes and maintains the Product Vision.
Feature Validation uses that Product Vision to assess proposed features and provide recommendations.
Unlike Gentlii Foundations, Gentlii Skills does not require a comprehensive product strategy, charter, or governance framework.

**The goal is simple: Define the product. Validate the features. Build what matters.**
